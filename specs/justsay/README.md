## 这是什么

能说会道(code: justsay,zh: 能说会道,en: Just Say Ai)是面向中国市场的中文优先 AI 语音工具:
**口述成文 / 翻译 / 随便问**,跨 iOS App + 共用云端后端 + Mac 桌面端。

代码不在本仓库:iOS App 与后端在独立的 `JustSayAi/` 仓库(iOS 主 App + 键盘扩展 + `server/` FastAPI「大脑」)。
本目录只放**方案与数据逻辑文档**,作为多端 / 多 session 的单一事实来源。

## 当前关键结论(速览)

```
架构:    瘦客户端 → /v1/audio(ASR)+ /v1/polish(成文/翻译/随便问),逻辑全在服务端
ASR:     豆包小时版按量(~¥0.8/h),不买并发版;多厂商主备 + 文件识别削峰 + 自建 SenseVoice 兜底
路由:    建议 file-first 默认(更准 / 占并发更少 / 无中转),流式作会员"实时上屏"增值后置
成本:    COGS ≈ 100% ASR;每用户满额 ~¥3/月,实际人均 ~¥0.5~1/月
额度:    免费 10000 字/周(双闸:字数闸 + ¥1/周·¥5/月 成本安全闸防刷)
会员:    无限字数(fair-use 软顶,防重度亏穿)· 月 ¥19.9 / 年 ¥98~128
返佣:    单层返佣(微信红线)· 代金券内循环 · 限期不终身 · 冻结期 + 退款追回
玩法:    近场零成本先做(人设文风改写 + 激励视频换额度);远场验证(配音 TTS + 声音复刻 = 配音体验)
登录:    App / 桌面 / Web 接微信扫码;同一开放平台账号下用 unionid 统一用户
```
