# Word list

High-frequency entries from the Google Developer Documentation Style Guide word list. The live list is far longer and changes. For a word that is not here, fetch <https://developers.google.com/style/word-list>.

## Do not use

| Word | Use instead |
| --- | --- |
| `abort` | `stop`, `exit`, `cancel`, `end` |
| `access` (verb) | `see`, `edit`, `find`, `use`, `view` |
| `account name` | `username` |
| `actionable` | `useful`, or say what the reader can act on |
| `agnostic` | `platform-independent`, or another precise term |
| `aka` | `also known as`, parentheses, or a definition |
| `allows you to` | `lets you` |
| `and/or` | Rewrite. Acceptable only where space is tight, such as a table. |
| `anti-pattern` | Name the specific mistake. |
| `best effort` | Say what the system actually does. |
| `blacklist`, `whitelist` | `blocklist`, `denylist`, `allowlist` |
| `blind to` | `ignores`, `unaware of`, `disregards` |
| `chapter` | `document`, `page`, `section` |
| `click on` | `click` |
| `comprise` | `consist of`, `contain`, `include` |
| `currently`, `presently`, `as of this writing` | Delete it. |
| `desire`, `desired` | `want`, `need` |
| `deselect`, `uncheck` | `clear` |
| `e.g.` | `for example` |
| `easy`, `easily`, `simple`, `simply` | Delete it, or state the actual number of steps. |
| `hit` | `click`, `press` |
| `i.e.` | `that is` |
| `in order to` | `to`, unless the longer form genuinely reads better |
| `just` | Delete it, or use `only`, `instead`, `previously`. |
| `kill` | `stop`, `exit`, `cancel`, `end` |
| `leverage` | `use`, `build on`, `take advantage of` |
| `native` (of a person) | Rewrite. For software, `built-in`. |
| `once` (meaning after) | `after` |
| `please` | Delete it in instructions. |
| `sanity check` | `final check for completeness and clarity` |
| `slave` | `replica`, or a domain-specific term |
| `tag` (meaning a whole HTML element) | `element` |

## Use with care

| Word | Rule |
| --- | --- |
| `above`, `below` | Not for a version range: use `later` and `earlier`. Not for a position in a document: use `preceding` and `following`. |
| `AI` | No need to expand to `artificial intelligence`. |
| `admin` | Write `administrator` unless it is a literal UI label. |
| `among`, `between` | `between` for distinct things, `among` for membership in a group. |
| `appears`, `display` | `display` is transitive. An area does not "display"; something displays content in it. |
| `can`, `may`, `might`, `must` | `can` for ability or permission, `might` for possibility, `must` for a requirement, `may` for policy and legal text only. |
| `checkbox` | One word. `select` to mark it, `clear` to unmark it. |
| `click`, `tap` | `click` for a pointer, `tap` for touch. |
| `deprecate` | Means recommended against. It does not mean removed, deleted, or shut down. |
| `each` | Refers to individuals, not a group. Not a synonym for `all`. |
| `either` | Two choices, with parallel syntax. |
| `email` | One word, never capitalized mid-sentence, never a verb. |
| `enter`, `type` | `enter` for text input generally. `type` when the literal keystrokes matter. |
| `execute` | Use `run` when that is what you mean. |
| `internet` | Lowercase except at the start of a sentence, heading, or list item. |
| `later`, `earlier` | Use for version ranges, with version numbers. Not `higher` and `lower`. |
| `log in`, `login` | `login` is the noun or adjective, `log in` is the verb. `sign in` is usually better. |
| `master` | Never paired with `slave`. Prefer `primary`, `main`, `parent`. |
| `on-premises` | Hyphenated, and always with the `s`. Not `on prem`, `on premise`, or `on-premise`. |
| `should` | Allowed for an expected action or advisable state. In prescriptive text, say `must`, `We recommend`, or `can` instead. |

## Not in the word list

These are not word list entries, but the surrounding guidance covers them. Do not cite them as word list rules.

- `ensure` and `guarantee`: constrained by the excessive claims page, not the word list.
- `utilize`, `via`, `since`, `note that`: no entry. The plain language and tone guidance still favors `use`, `through` or `by`, `because` or `after`, and deleting the filler.
